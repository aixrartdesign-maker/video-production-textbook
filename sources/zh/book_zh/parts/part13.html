背景 23

把电视掉转过来的人

1963年，《音乐博览会——电子电视》在德国伍珀塔尔的一家小画廊开幕。展厅里摆着13台电视。有的画面扭曲；有的会在观众踩下脚踏板或对着麦克风发声时改变图像。这是1932年生于首尔的白南准的首次个展，如今被称为视频艺术的起点。

当时的电视，是在家里接收电视台所播内容的设备。白南准要扭转这种单向流动。他让观众介入画面，后来还自己造出视频合成器，用手塑造视频信号。他把接收的媒介变成了创作的媒介。

他于1962年加入激浪派，投身抹去日常生活与艺术界线的运动；1958年结识约翰·凯奇之后，又把东方的时间观带入创作。在《电视佛》（1974）中，一尊佛像坐在电视机前，凝视着摄像机传回的自身影像。冥想与闭路电视，东方的循环时间与西方的电子技术，在一块屏幕上相遇。

他的眼光也不止于作品。1974年，他在提交给洛克菲勒基金会的提案中首次使用“电子超级高速公路”一词，比互联网广为人知早了20年。1984年1月1日，他播出《早安，奥威尔先生》，用卫星把纽约、巴黎和首尔连在一起直播。奥威尔把1984年想象成监控之年，白南准偏要在这一年展示另一面：技术也能把人连接起来。

《多多益善》是为1988年首尔奥运会在韩国国立现代美术馆（MMCA）果川馆建造的电视塔，由1,003台电视叠成，高18.5米。它在2018年熄灭，经过4年7个月的保存修复，于2022年重新点亮。这次修复暴露了媒体艺术最棘手的问题。零件一旦停产，作品以什么形态存续？后文讨论的保存问题，就从这里开始。

13.1

什么是媒体艺术？

媒体艺术与其说是一种类型，不如说是一种态度。它是一个统称，指那些以所处时代的新媒介为材料，探究这些媒介如何改变人与世界的创作。20世纪60年代是电视，90年代是互联网，如今则是传感器、数据和生成模型。

为什么有这么多名称

视频艺术20世纪60年代后期

  • 随便携式录像设备的普及而出现
  • 扭转电视的语言，或用闭路电视让观众看到自己

媒体艺术更宽泛的名称

  • 材料从视频扩展到计算机、网络和传感器后开始使用

新媒体艺术20世纪90年代起

  • 以数字技术和互联网为前提的创作
  • 弱点：“新”会随时间变旧

后网络艺术互联网变得像空气一样之后

  • 有争议的术语，学界尚无公认定义
注意

这些术语不必背。但如果不懂含义就借来形容自己的作品，评审一眼就能看穿。

帮你读懂文献的概念

术语含义提出者
生成艺术由预设的规则系统生成的作品，通常带有偶然因素泰特美术馆术语表的定义
互动性观众的行为改变作品的状态媒体艺术的核心条件
场域特定与某一场所的条件紧密相连的作品也是国际公开征集中的一个类别

13.2

视频与媒体艺术有何不同

哪里不同？读到这里，你已经具备了所需的大部分技能。读画面、布光、衔接镜头、处理声音，全都照样适用。变的不是技能，而是前提。

有两点相同。两者都是时基媒介，所以长度、节奏、重复、静止都是表达手段；拍摄、布光、剪辑、调色、声音这套制作流程也依然需要。屏幕越大，基本功越藏不住。

普通视频

  • 观众位置 — 坐在屏幕前
  • 开头与结尾 — 固定
  • 画幅比 — 可随媒介改变
  • 设备 — 展示成果的手段
  • 完成 — 交付即结束
  • 重复 — 以只看一遍为前提

媒体艺术

  • 观众位置 — 走进空间并在其中移动
  • 开头与结尾 — 观众随时进出
  • 画幅比 — 作品的条件，改动即损坏
  • 设备 — 往往是作品的一部分
  • 完成 — 整个展期运行完才算结束
  • 重复 — 以每天循环数百遍为前提
提示

把起承转合原样搬过来，多数观众只看到“转”就走了。无论从哪里看起，都必须在30秒内看懂。

学生最容易忽略的：开头与结尾

循环设计让结尾接上开头

  • 最后一帧与第一帧相似，接缝就消失了

进入点从哪里进来都能看懂

  • 定期重复关键画面

长度2到7分钟之间

  • 再长，看到最后的人就会大减

为什么必须保持画幅比

媒体艺术保存机构的安装指南规定，作品的画幅比必须保持，并指出为适应屏幕而放大或裁切并非恰当做法。在视频制作中，为竖屏重新剪辑是家常便饭；但对艺术作品来说，这个行为本身就改变了作品。在这里，你必须放下每换一种媒介就重新构图的习惯。

制作展览影像，要以没有人从头看起为前提。让它从任何进入点都能看懂，这就是设计。13.2 视频与媒体艺术有何不同

13.4

工具地图

用什么来做？剪辑工具产出的是一个固定的成品，而媒体艺术工具做的通常是“持续实时运行的程序”。你设计的是运行，而不是完成。

结构

用三个方框来读互动媒体艺术：传感器输入（摄像头、深度、麦克风、触摸）→处理（TouchDesigner、Unity、p5.js）→输出（投影、LED、声音）。下面的工具地图也按同样的顺序排列。

生成实时影像的工具处理

  • TouchDesigner — 连接节点生成实时影像。在一个窗口里串起传感器 · 声音 · 视频 · 投影输出；展览中用得最广的工具，非商业许可下免费
  • Unreal Engine · Unity — 游戏引擎。3D空间、VR · AR、虚拟制片。摄影机和布光的概念可以直接沿用
  • Processing · p5.js — 用代码画画。生成艺术的基础；p5.js直接在浏览器里运行，入门门槛最低
  • Max/MSP · Pure Data — 声音与信号。用于以声音为主或对声音有反应的作品

接收输入的工具输入

  • 深度摄像头 — 人的距离和姿态。动作感应类作品的基本输入
  • 激光雷达（LiDAR） — 把空间扫描成点。用于大空间的位置追踪和空间数据化
  • Arduino · Raspberry Pi — 驱动传感器和电机的小型计算机。读取光 · 声音 · 距离 · 压力，再转化为影像
  • 摄像头与视频分析 — 一台摄像头就能做动作检测、轮廓提取、人脸追踪。没有预算时最现实的选择

发送输出的工具输出

  • Resolume — 实时播放和混合视频。演唱会和夜店视觉的标配
  • MadMapper — 投影映射专用。把影像贴合到非平面的表面上
  • NDI · Syphon — 在程序之间实时传递视频的通道。机器一多就必不可少
提示

别先选工具。先用一句话写下“观众做什么，就会发生什么”，再去选，选项自然缩到两三个。

13.5

让作品在展厅里运转

在工作室里能运转，和在展厅里连续一个月天天运转，是两个完全不同的问题。一件媒体艺术作品的口碑，往往不取决于完成度，而取决于“有没有熄过”。

光与距离

1/4屏幕面积变为4倍时的亮度。亮度以ANSI流明标示；同样的输出，屏幕越大看起来越暗
约3m用投射比1.5的镜头投出2米宽画面所需的距离。先量空间，再选镜头
  • 环境光 — 在明亮的展厅里，黑色会浮成灰色。如果暗部很重要，就把遮光作为参展条件。
  • 投影面 — 白墙最稳妥，但表面纹理会损失分辨率。深色表面能让黑色更深，却会让整体变暗。
注意

屏幕保护程序、睡眠模式和自动更新，是展览期间重启最常见的原因。全部关掉。

保持运转

  1. 01自动启动 — 通电后，程序应在无人值守的情况下自行启动。操作系统自动登录和开机启动项是基本设置。
  2. 02禁用省电 — 关闭屏幕保护程序、睡眠模式和自动更新。
  3. 03定时重启 — 让它每天开馆前重启一次，错误就不会累积。
  4. 04备用版本 — 另外把作品导出成普通视频文件。实时作品一旦停摆，至少还能播放它。

现场要带的东西

物品原因
插线板、延长线插座永远不够
备用视频线线材故障是现场最常见的问题
转接头套装每台设备的接口都不一样
黑胶带 · 扎带安全和美观都需要
安装照片和设置记录下次展览可以原样重现
打印好的作品标签现场的标签常常迟到

安全与责任

  1. 01线缆 — 线缆要避开观众动线。实在避不开，就加装线槽盖板。
  2. 02亮度与闪烁 — 快速闪烁可能诱发部分观众癫痫发作。避免1秒内闪烁超过三次；如有闪烁，在入口处张贴提示。
  3. 03声音 — 调好音量和方向，以免影响相邻作品。可考虑指向性音箱或耳机。
  4. 04摄像头与隐私 — 如果作品用摄像头拍摄观众，要说明是否录像；如果不保存影像，也要写明。
要为展览的最后一天而设计，而不是第一天。一个月后仍在运转，是作品的一部分。13.5 让作品在展厅里运转

PART 13媒体艺术与扩延电影
13.6

作品阐述与作品集

在媒体艺术中，文字是作品的一部分。观众靠读阐述来理解作品，公开征集和驻留项目也只凭文字和照片评审。要求与视频作品集不同，需要单独练习。

作品阐述的结构

01是什么以“这件作品是……”开头。从背景讲起，没人会读到最后
02怎么做观众做什么，就会发生什么。这是互动作品的使用说明
03为什么必须采用这种形式的理由。是选择的依据，而不是技术展示
提示

展厅墙面文字在150到300字之间才有人读。再长，就没人站在那里读了。

应避免的词

  • 空泛的大词 — “存在”“关系”“边界”不加解释地使用，等于什么都没说。要用的话，至少具体说明一次它在这件作品里指的是什么。
  • 罗列技术 — 工具写在材料栏里。在阐述中炫耀工具，只会让作品显得小气。
  • 未经核实的引用 — 不要引用没读过的书。评审最先问的就是这个。

作品集里放什么

项目内容常见错误
主要图片展场全景1张、细节2张只有截屏
记录视频1–2分钟，含观众反应只拍屏幕的冗长画面
材料栏媒介、尺寸、时长、年份完全漏掉
系统图1张输入-处理-输出流程图只用文字说明
安装要求空间、电源、遮光条件评审无法判断能否安装
贡献度在合作作品中你承担的部分把团队作品做得像个人作品

记录让作品活下去

媒体艺术作品在展览结束时就消失了。留下的只有记录，下一次公开征集和下一场展览都由它决定。展览期间，务必拍下展场全景、细节、观众的真实反应，乃至安装过程。

展厅里最重要的一天不是开幕日，而是拍记录的那一天。13.6 作品阐述与作品集
练习13.6
任务
为自己的一件作品写一段250字的展览阐述，并做一页作品集。要包含材料栏、系统图和安装要求。
提示
写完后，请一位不了解作品的人读一读阐述，问他能否看出“自己该做什么”。

第一句是否定义了作品？安装要求是否具体到评审可以判断？
参考答案
把观众反应照片与系统图并排，一页之内同时说明看到什么和如何运作的版式。

PART 13媒体艺术与扩延电影
13.8

三场争论

沉浸、AI、保存。学媒体艺术，就会碰上三场争论。哪一场都没有定论，所以目标是了解各方立场的依据，再决定自己站在哪里。

争论一 — 沉浸式展览：艺术还是商品

商品论

  • 韩国的一项研究把沉浸式展览定义为“超出艺术中介、以沉浸体验本身为目的的商业内容”
  • 门票 — 海外沉浸式展览的成人票价从数万到十余万韩元不等；韩国公立美术馆大多在1万韩元左右
  • 一位业内CEO坦言 — “像海浪这样的题材谁都能做，所以借用创意和侵犯著作权很难举证”

必要论

  • 当一切都能在家观看时，沉浸式体验给了人们亲自到场的理由
  • 公立美术馆也在吸纳 — MMCA的2026年光主题展览、首尔市立美术馆的新媒体分馆

思考题

一件用150万韩元预算制作、每晚在城市屏幕上放映四小时的作品，与每年吸引数百万观众的收费场馆，是同一种媒体艺术吗？区分它们的是什么：媒介、资金来源，还是观众所站的位置？

术语

作者身份的两条脉络 — 把AI当工具用的创作，不同于以AI本身为主题的创作。这是使用工具与质疑工具的区别。

争论二 — 生成式AI与作者身份

2024年的空白当时没有规则

  • 一件生成式AI作品在公益广告大赛中获得大奖，随后引发争议
  • 主办方表示“没有AI条款，既无法禁止，也无法鼓励”，奖项维持不变

2026年的转变要披露，而非禁止

  • 中央媒体艺术大赛 — 鼓励AI辅助，大量使用者另组评审，必须披露是否使用及使用范围
  • 国家报勋部的征集 — 要求写明所用工具 · 使用范围，乃至参考来源
  • 某国际学术会议的艺术单元 — 必须说明AI所起的作用

质疑工具的创作2026年“韩国年度艺术家奖”入围者

  • 用AI修复一部1946年的电影，揭示“技术无法完全复原历史”
  • 审视视频生成模型中内含的偏见

2年之间，“AI使用：无规定”变成了“AI使用：必须申报”。在制作日志里记下用了哪些工具、用在哪里、用了多少，这个习惯就是你日后的申报材料。

争论三 — 作品如何存续

737台《多多益善》修复中受损的CRT，已修理或以二手零件更换
266台顶部的小型显示器，换成了保留原貌的平板显示器。8段影像转为数字格式
每周4天，每天2小时2022年9月重新启动以来的运行时间，为的是保护作品
  • 悬而未决的问题 — CRT换成平板屏幕之后的《多多益善》，还是同一件作品吗？保存指南把装置分为两种情况：“设备是作品本身的一部分”，以及“设备只用来展示作品”。在前一种情况下，更换设备就意味着改变作品。
  • 学生现在能做的 — 把软件及版本、硬件、设置，以及“哪些可以改、哪些绝不能改”记录下来，作品在多年后就能重新展出。
  • 保存作为职业 — 2026年，MMCA开设了涵盖新媒体的保存修复师培训课程。不只是创作，守护作品也正在成为一种职业。
作品完成当天，写一页技术规格说明。这页纸就是10年后重新点亮作品的钥匙。13.8 三场争论

参考答案

PART 13小结

一页总结

13.1 什么是媒体艺术

是态度，不是类型。只要确认能用一句话说清为什么非用这种媒介不可。

13.2 视频与媒体艺术有何不同

不同的是前提，不是技术。观众中途走进来，所以要设计循环和进入点，并尊重画幅比。

13.3 韩国媒体艺术版图

三条脉络：机构、城市屏幕、沉浸式产业。学生先登上城市屏幕，积累履历。

13.4 工具地图

分成处理、输入、输出来看。先写下观众做什么就会发生什么，再选工具。

13.5 让作品在展厅里运转

算好投射比和亮度，靠自动启动、禁用睡眠、每日重启和备用版本，让它运转到最后一天。

13.6 作品阐述与作品集

是什么、怎么做、为什么，写在150–300字以内。别漏掉材料栏、系统图、安装要求和贡献度，并拍好记录。

13.7 公开征集与资助

从设有学生组的征集入手。一学期内备齐四样：韩文创作阐述、英文策划案、30秒精华视频、3分钟影片。

13.8 三场争论

沉浸式展览的性质、AI的披露标准、零件停产与保存。了解各方依据，再决定自己的立场。
